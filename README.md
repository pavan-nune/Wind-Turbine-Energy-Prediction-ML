# 🌬️ Wind Energy Intelligence System

A Machine Learning–based web application that predicts wind turbine energy output using weather conditions.

## 🚀 Project Overview
This project uses a Random Forest Regressor trained on historical wind turbine data to predict actual power generation based on:
- Wind Speed
- Theoretical Power Curve

The trained model is integrated into a Flask web application with a professional dashboard-style UI.

## 🧠 Technologies Used
- Python
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
- Flask
- HTML & CSS
- Jupyter Notebook
